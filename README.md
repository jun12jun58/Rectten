# Rectten
숫자 블록을 드래그해 영역을 만들고, 숫자의 합을 10으로 만들어 블록을 터뜨리는 퍼즐 게임.

## 플레이 방법
1. 마우스 드래그 또는 터치로 직사각형이나 정사각형 영역을 지정한다.
2. 지정한 영역 안 숫자의 합이 10이 되면, 손을 뗐을 때 해당 영역의 블록들이 터진다.
3. 블록이 터지면 위에 있던 블록들이 아래로 떨어져 빈자리를 채우고, 맨 위에 새로운 블록이 생성된다.

## 폭탄
- 영역을 지정할 때 폭탄 블록은 숫자 0으로 계산된다.
- 사각형에 포함시키거나 폭탄 블록을 직접 클릭하면 폭탄을 중심으로 3*3 영역의 블록이 터진다.

## 게임 목표
시간 제한 안에 블록을 터뜨려서 최대한 많은 점수 얻기.
